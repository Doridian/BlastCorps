# The ROM's remakeable assets in the game's data: images, vertices and the
# display lists that draw them (docs/DISTRIBUTION.md).  The port's executable
# carries none of them: blastcorps/src defines them under ASSET_INIT (common.h),
# so the port's are zeros, asm2c.py writes zeros for its three, and at startup
# port/host/romdata.c's port_rom_fill fills them from the user's ROM (or a
# pack's modules' data), by the table port/tools/gen_fill.py makes from this
# list and the version's N64 link.  The names are us.v11's (every version
# has them all, with the same bytes but for the lists' addresses).
#
#   module  symbol[+offset]  kind  count  source  [what the port fills]
#
# kind: bytes (as the ROM has them, whatever the declared type: what the RDP
# reads), vtx (count Vtx, each field to host order), gfx (count commands:
# each word from the ROM, an address the N64 link relocates becomes the host
# address of what it points at, a segment address gets gbi.h's G_SEGTAG).
# source: the file that defines it (asm: asm2c.py's, from the asm data).
# The last column, where it isn't the symbol, is a field of a structure
# (the structure's other fields are parameters and stay initialized).
