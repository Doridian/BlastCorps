# ptr32_check.py's allow-list: the structures (and unions) whose pointers
# are still PTR32 in the LP64 build, a name a line (us.v10's build: asm2c's
# D_X_t types are a version's own; a union or structure with no name is
# its container's name and member's, `Update.a`), each with the package
# that makes it native.  P6 took out everything else; what is left is
# P7's (libaudio, whose records are allocated and cast at the N64's sizes
# and whose banks and sequences are ROM data; the sound player; the audio
# DMA; the level's tables) and P8's (the display list and audio command
# words).  P10 has none here (its host interface is ptrcast_scan.py's).
# ptr32_check.py BUILD --update rewrites it, keeping each name's note.
