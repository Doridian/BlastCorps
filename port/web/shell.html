Menus and the map: arrows/WASD, Enter = select, Escape = back, or the mouse or a finger (drag the globe, click a level). Driving: W/S = accelerate/brake, A/D = steer, Space = brake/get out, Shift = special, Q/E = camera, Escape = pause. X/C/Z = A/B/Z, IJKL = C buttons; a gamepad works too.
